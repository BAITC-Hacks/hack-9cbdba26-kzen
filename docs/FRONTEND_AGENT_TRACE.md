# Для фронта: лента агента и обоснование словами

Два поля бэкенд уже отдаёт, но экраны их не показывают. Без них агент на демо
невидим: жюри увидит «кнопку Рассчитать», а не шаги. Третья ручка — новая.

## 1. Лента шагов агента после расчёта

`POST /api/v1/calculations` → в ответе поле `agent`:

```json
{
  "agent": {
    "version": 1,
    "trace": [
      {"seq": 1, "type": "decision", "status": "ok",
       "title": "Цель: сформировать заказ", "tool": "", "sku": "",
       "facts": {"supplier": null, "category": null, "skus": 3909}},
      {"seq": 2, "type": "tool_call", "status": "warning",
       "title": "Проверено качество данных", "tool": "inspect_data_quality", "sku": "",
       "facts": {"skus": 3909, "insufficient_data": 215, "examples": {"ATN000330": ["нет кода 1С"]}}},
      {"seq": 3, "type": "tool_call", "status": "ok",
       "title": "Рассчитана потребность", "tool": "calculate_orders", "sku": "",
       "facts": {"positions": 809, "units": 123456}},
      {"seq": 4, "type": "tool_call", "status": "warning",
       "title": "Рекомендации проверены на аномалии", "tool": "screen_recommendations", "sku": "",
       "facts": {"one_off_suspected": 870, "frequent_stockout": 701, "large_order": 201}},
      {"seq": 5, "type": "tool_call", "status": "warning",
       "title": "Разобрана история продаж", "tool": "review_one_off", "sku": "081100392_",
       "facts": {"removed_units": 394, "share_of_history": 0.83, "months": ["2026-04-01"]}},
      {"seq": 6, "type": "tool_call", "status": "ok",
       "title": "Проверены ограничения поставщика", "tool": "check_supplier_constraints",
       "sku": "081100392_",
       "facts": {"quantity": 5, "moq": 1, "multiple_ok": true, "monthly_demand": 6.5,
                 "months_of_demand": 0.8}},
      {"seq": 15, "type": "decision", "status": "ok",
       "title": "Рекомендации сформированы", "tool": "", "sku": "",
       "facts": {"ready": 2802, "needs_review": 1368, "insufficient_data": 215}},
      {"seq": 16, "type": "awaiting_approval", "status": "waiting",
       "title": "Ожидает утверждения менеджером", "tool": "", "sku": "", "facts": {}}
    ]
  }
}
```

Поля:

| Поле | Значения | Как показывать |
|---|---|---|
| `type` | `decision`, `tool_call`, `observation`, `flag`, `awaiting_approval` | иконка шага |
| `status` | `ok`, `warning`, `blocked`, `waiting` | цвет: зелёный, жёлтый, красный, серый |
| `title` | готовый текст на русском | заголовок строки |
| `tool` | имя инструмента или пустая строка | мелким серым под заголовком |
| `sku` | код 1С или пустая строка | ссылка на карточку `IEK:<код>` / `SE:<код>` |
| `facts` | словарь число/строка/список | таблица «ключ: значение» под строкой, можно свернуть |

Шаги с `sku` = «» относятся ко всему ассортименту, шаги с кодом — к одной позиции.
Смысл ленты для демо: после `screen_recommendations` агент **сам** добавляет
`review_one_off` и `check_supplier_constraints` по подозрительным позициям.
Заголовок панели: «Ход работы агента», рядом счётчик шагов.

## 2. Шаги агента в карточке позиции

`GET /api/v1/skus/{sku_id}/explanation` → поле `agent_trace`: те же события,
только по этой позиции (обычно 0–2 штуки). Показывать блоком «Что проверил агент»
под формулой. Пустой список — блок не рисовать.

## 3. Обоснование словами (новая ручка)

`GET /api/v1/skus/{sku_id}/narrative` → `{"text": "...", "source": "..."}`

Ручка медленная (до 8 с, если LLM думает), поэтому вызывается **отдельно** после
карточки: карточка рисуется сразу по `explanation_text`, текст подтягивается
следом и заменяет его в том же блоке. Пока ждём — скелетон или «формулирую…».

`source` показывать мелким текстом под обоснованием:

| `source` | Что значит | Подпись |
|---|---|---|
| `nvidia:meta/llama-3.3-70b-instruct` | текст от LLM, все числа проверены против расчёта | «сформулировано ИИ, числа из расчёта» |
| `template (LLM недоступна)` | сети или ключа нет, показан шаблон из компонентов расчёта | «шаблон» |
| `template (LLM добавила числа, текст отброшен)` | модель придумала число, сервис его не пропустил | «шаблон» |
| `none` | нарратор выключен в настройках | «шаблон» |

Ответ кэшируется по коду и количеству: повторное открытие карточки мгновенное.
