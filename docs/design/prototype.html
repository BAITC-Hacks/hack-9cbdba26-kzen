# Handoff: сервис закупщика «Электрокомплект» ## Обзор Рабочее место менеджера отдела закупа. Для склада «Алматы» и выбранной категории сервис рассчитывает регулярную потребность и предлагает заказ по каждому артикулу, группирует позиции по поставщикам (Systeme Electric, ИЭК) и объясняет расчёт. Менеджер может изменить количество с указанием причины, затем отправляет список на согласование руководителю и экспортирует утверждённую версию. ## Файлы пакета | Файл | Что это | |---|---| | `prototype.html` | Автономный рабочий прототип, открывается двойным кликом без интернета.
